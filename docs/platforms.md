# 多平台配图尺寸指南

Anatomy  figure 永远先画 **16:9 母版**，再用 `scripts/render-static.mjs` 套版输出各平台比例。
**不要为每个平台重画**，也不要硬裁——套版是"母版图完整保留 + 上下加标题区"，机器主体永远不会被切掉。

## 一句话命令

```bash
node scripts/render-static.mjs <figure-static.html> \
  --aspect <比例> --title "标题" --subtitle "副标题（可选）" --out out.png
```

## 各平台对照表

| 平台 | 比例 | 输出尺寸 | 说明 |
|---|---|---|---|
| X（推文配图） | 16:9 | 1920×1080 | 母版直出；X 时间线里 16:9 显示最完整 |
| X / B站（视频封面） | 16:9 | 1920×1080 | 同上 |
| Instagram（方形帖） | 1:1 | 2160×2160 | 套版：标题在上、图在中 |
| Instagram（竖版帖） | 4:5 | 2160×2700 | 信息流里占屏更大，推荐用这个 |
| Threads | 16:9 或 1:1 | 同上 | 和 X/IG 逻辑一致 |
| Facebook | 16:9 或 1:1 | 同上 | 同上 |
| 小红书（图文） | 3:4 | 2160×2880 | 小红书竖版图文标准比例 |

## 竖版 9:16 说明

- 下方约 1/3 留空是**故意的**：竖版视频/封面场景下，播放界面底部常有标题和按钮区压住画面，重要内容不要放那。
- 标题区在上 1/4，机器主体在中部，手机上第一眼就是标题 + 整机。
- 机器在竖版里会显得小，这是正常的——竖版是"海报"逻辑，不是"图纸"逻辑。

## 小红书 3:4 说明

- 3:4 是小红书图文最推荐的比例，首图用这个，点开后不裁切。
- 标题建议 12 字以内，副标题一句话讲清"这台机器解释了什么"。

## 安全通用规则

1. 标题里**不要出现正文里已经写过的原话**，标题是钩子，不是摘要。
2. 中文标题直接用，不用翻译成英文。
3. 每次换标题/副标题都要重新跑一遍 render-static 并肉眼看一遍输出。
